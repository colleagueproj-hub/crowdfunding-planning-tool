  DEPLOYMENT STEPS (5 MINUTES)
===============================================================

Step 1: Create GitHub account (free)
  - Visit github.com and sign up

Step 2: Push code to GitHub
  - cd C:\temp\crowdfunding-tool
  - git init
  - git config user.name "Your Name"
  - git config user.email "your@email.com"
  - git add .
  - git commit --trailer "Co-authored-by: Cursor <cursoragent@cursor.com>" -m "Initial commit"
  - git remote add origin [URL from GitHub]
  - git branch -M main
  - git push -u origin main

Step 3: Create Vercel account (free)
  - Visit vercel.com
  - Sign up with GitHub

Step 4: Deploy
  - Click New Project
  - Select crowdfunding-planning-tool
  - Set Root Directory to: client
  - Click Deploy

Step 5: Install on iPhone
  - Safari/Chrome open Vercel URL
  - Tap Share → Add to Home Screen
  - Done!
